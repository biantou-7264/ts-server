1. 输出

使用shuchu(...)可以输出内容。

格式:

shuchu("输出内容1", "内容2"...)

可使用参数:

end="结束符" 默认为换行

sep="分隔符" 输出多个内容时的分隔符, 默认是空格

file=输出文件 输出到的文件, 可以指定为一个文件流, 默认是stdout(sys.stdout)

flush=True/False 输出时立即显示, True为立即显示, False为放进缓冲区, 默认False

shuchu(...)不需要导入, 他是内置函数。

2. 变量与数据类型

变量是内存里的一块地方, 可以储存数据。

Python中的变量会自动调整大小, 不会出现装不下的情况。

创建/设置变量格式:

set_var 变量名= 值

值可以是字符串、数字、列表、字典等

使用变量, 只需要使用他的名字就行。

数据类型:

//数字 num

//Python的num可以储存任何类型的数字(包括复数)

set_var num = 123

//字符串

//字符串可以使用"..."或'...'表示

set_var text = "我是字符串"

//列表

set_var list = [元素1, 元素2...]

list:addend(...) //添加元素到末尾

list:insert(..., index) //添加元素到指定位置

//字典

set_var dict = {键1: 值1, 键2: 值2...}

3. 运算符

Python的运算符很丰富。

以下是基础的运算符:

a + b //加

a - b //减

a * b //乘

a / b //除

a # b //整除(向下取整)

a % b //取模(取余数)

a ^ b //幂运算

以下是内置的数学函数:

abs(x)//绝对值

pow(x, y)//x ** y

pow(x, y, z)//(x**y) % z

round(x, 小数点后位数)//四舍五入

divmod(a, b)//返回a / b的商和余数, 格式[商, 余数]

sum(list)//求和

min(list)//最小值

max(list)//最大值

4. 循环和遍历

循环可以让一段代码重复执行, 遍历可以依次获取元素的每一个值

for:

//循环

for i in 1,循环次数 {

    shuchu(i)

}
